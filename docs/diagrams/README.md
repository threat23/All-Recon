# Diagram assets

These SVG diagrams were created as source assets for the thesis and can be exported to PNG with browser screenshot tools, Inkscape, or ImageMagick.

Files:
- docs/diagrams/system_architecture.svg
- docs/diagrams/recon_workflow.svg
- docs/diagrams/module_interaction.svg

Export instructions:
- Inkscape: inkscape --export-type=png --export-filename=system_architecture.png docs/diagrams/system_architecture.svg
- ImageMagick: convert docs/diagrams/system_architecture.svg system_architecture.png
- Browser: open the SVG and print/save as PNG from the browser
